# sentinel-exploration

Getting familiar with Sentinel-1 and Sentinel-2 data before starting my main project. Everything is done in Google Earth Engine over Dhaka, using 2026 data.

- `1_setup_and_check` - EE login + a quick test
- `2_sentinel2_testing` - bands, metadata, cloud masking, indices, composites
- `3_sentinel1_testing` - VV/VH, speckle, ascending vs descending

To run:

```
pip install -r requirements.txt
```
